# 职升机 Careerfly

> 让专家经验成为可以追问的答案，让职业探索走向具体行动。

职升机 Careerfly 是一个面向大学生的 **AI 职业决策与求职规划平台**。通过职业成长工具与专家数字分身咨询，帮助用户认识自己、理解真实岗位，并持续推进求职准备。

我们希望，每个处在职业选择路口的人，都能找到适合自己的经验参考，把“我该往哪里走”的困惑，逐步变成有依据的判断和可执行的计划。

## 为谁而做

职升机关注处于职业方向探索期、有学长学姐或行业专家咨询需求的大学生，尤其是正在面对这些问题的你：

- **还不确定自己适合什么。** 有兴趣，也有一些经历，但不知道它们能对应哪些职业方向。
- **想了解岗位真实的一面。** 看过招聘要求和经验分享，仍想知道日常工作、能力要求，以及选择这个方向意味着什么。
- **需要结合自身情况的建议。** 面对多个方向，希望有人理解自己的背景、偏好与现实约束，陪自己把问题问清楚。
- **有目标，却不知道如何开始。** 需要明确准备顺序、阶段任务，并根据实践结果及时调整。

## 产品如何帮助你

### 职业探索：逐步认识自己

从问卷、小游戏和探索任务开始，梳理兴趣、能力与职业偏好，形成个人职业画像 **Career Profile**。

画像围绕个人背景、职业目标和探索经历持续积累，帮助你看见已有优势、需要补足的能力，以及值得进一步验证的方向。

### 专家数字分身：向有相关经验的人持续追问

选择真实学长学姐或一线从业者对应的专家数字分身，通过文字或语音讨论职业问题。

数字分身以专家的职业经历、岗位经验、行业知识、个人观点和判断方式为基础，让经验能够通过对话回应具体处境。你可以继续补充背景、追问理由、讨论取舍，逐步形成自己的判断。

| 咨询主题 | 可以从这样的问题开始 |
| --- | --- |
| 职业方向选择 | 我的兴趣和已有经历，更值得先尝试哪个方向？ |
| 真实岗位认知 | 这个岗位每天在做什么？有哪些容易被忽略的要求？ |
| 人岗适配判断 | 我的优势在哪里？还有哪些能力需要通过实践验证？ |
| 求职路径规划 | 如果以这个岗位为目标，接下来应该按什么顺序准备？ |
| 个性化职业困惑 | 当成长空间、收入和稳定性发生冲突时，我该如何权衡？ |

### 游戏化成长：把目标拆成能完成的任务

通过职业探索任务、求职闯关和阶段进度，把抽象的职业目标拆成具体行动。

每完成一次探索、一次练习或一项准备，都留下可以复盘的结果，让你知道自己走到了哪里，以及下一步需要做什么。

### 路径记录：让每次探索都有积累

记录职业目标、探索经历与任务结果，随着行动反馈持续更新职业画像。

当你再次遇到关键问题时，可以带着新的经历和更明确的背景进入咨询，让建议与当前阶段相匹配。

## 从困惑到行动

职升机围绕这样一条路径设计：

**职业探索 → 形成画像 → 持续行动 → 遇到关键问题 → 专家分身咨询 → 获得建议 → 执行反馈 → 更新画像**

职业探索是可选的起点。如果已经有明确的问题，也可以直接选择合适的专家数字分身开始咨询。

例如，一位正在考虑产品经理方向的同学，可以先梳理自己的兴趣与项目经历，再向相关领域的数字分身了解岗位要求，讨论经历与目标之间的距离。随后，把建议拆成分析目标岗位、整理项目案例、开展相关实践等任务，再根据完成结果调整准备方向。

## 我们重视的体验

- **经验有明确来源。** 围绕真实专家的一手职业经历和判断组织咨询内容，让用户了解自己正在参考谁的经验。
- **问题可以持续追问。** 用户能够补充背景、讨论不同选择，获得与自身情况更相关的建议。
- **探索能够持续积累。** 将职业画像、咨询与行动记录联系起来，让新的经历成为下一次判断的依据。
- **咨询更容易获得。** 通过数字分身复用专家经验，降低时间与成本门槛，让更多大学生有机会获得职业指导。

## 服务模式与产品方向

产品采用 **免费职业成长工具 + 付费专家数字分身咨询** 的服务设计。

免费工具支持日常探索、任务推进与路径记录；付费咨询聚焦职业方向、岗位认知和求职路径等关键决策问题。

当前项目处于产品原型阶段，首期围绕三项核心能力推进：

1. **个人职业画像**：沉淀基础背景、职业方向与路径记录。
2. **游戏化职业探索**：通过任务、阶段进度和行动反馈支持持续成长。
3. **专家数字分身咨询**：帮助用户选择合适的经验来源，获得职业方向与路径建议。

随着产品完善，我们希望进一步连接咨询、行动与反馈，并通过同路人的经验分享、结伴成长和专家知识的持续更新，为职业探索提供更丰富的支持。
